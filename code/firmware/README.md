# ca65 ROM firmware for rosco_6502

This directory contains the ca65-based ROM firmware. It initializes the
hardware and includes WozMon, SD card access, read-only FAT32 support and
boot code that looks for `/ROSC0DE_6502.BIN` on the SD card (the filename
contains a zero in `ROSC0DE`). This is development firmware.

## Building

### Prerequisites

The Makefile requires these tools on `PATH`:

* cc65 toolchain: `ca65`, `ld65` and `da65`.
* GNU Make, Bash and standard command-line utilities including `cat` and `rm`.
* Optional: `minipro` for the ROM programming targets.

On Windows, use an environment that provides Bash and these utilities.
VASM and VLINK are not used by this directory's Makefile.

### ROM images

From the repository root:

```sh
cd code/firmware
make clean
make all
```

Or build one image after cleaning:

```sh
make boot8k.bin
# or
make boot32k.bin
```

The targets produce `boot8k.bin` (8 KiB) and `boot32k.bin` (32 KiB).
The 32 KiB build also produces four 8 KiB bank files,
`boot32k.0.bin` through `boot32k.3.bin`, which are concatenated into
`boot32k.bin`. Listings, symbols, maps and disassemblies are generated
alongside the images.

With a compatible programmer and `minipro` configured, `make burn8`
programs an AT28C64B and `make burn32` programs an AT28C256.

## Monitor and software

For WozMon, configure the terminal to display CR as CRLF and send a single
CR on Return. Use the symbols generated by the current build to locate
monitor routines rather than hard-coded addresses.

Example programs and filesystem utilities live in [../software](../software).
The ca65 examples use the firmware headers in [inc](inc); their Makefiles
also use `srec_cat` to generate Intel HEX files.
